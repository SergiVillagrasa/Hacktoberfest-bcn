# Fictional Gmail test messages

Copy these drafts into a dedicated test Gmail inbox. Replace the bracketed
addresses with accounts you control. Set the local fictional client profile's
email to the client test account's exact sender address. Keep real client names,
account numbers, and real financial details out of the test.

Send the first three messages in order as one Gmail conversation. Use **Reply**
for the manager message and the client's follow-up. Then send the final client
message in that same thread; open it in Gmail to test current-message capture.
Import the first three messages as explicitly labeled demo history. The final
message is the new message to analyze, not part of the imported history.
